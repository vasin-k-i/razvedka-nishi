# 🔍 Разведка ниши — скилл для Claude Code

Скилл, который проводит **разведку SEO-ниши перед сборкой сайта** и выдаёт готовую стратегию: вердикт go/no-go, карту спроса, деньги-страницы, контент-план и очередь первых страниц. Заточен под **РФ (Яндекс + Google, Wordstat)**.

Смысл простой: самая дорогая ошибка — потратить недели на сайт в нише, где либо не пробиться, либо не на чем заработать. Полдня разведки экономят эти недели. Рычаг — не «сделать красиво», а «не сделать зря».

## Что делает

Claude сам ведёт исследование по 8 фазам, ходит в живую выдачу, сверяет с реальностью и собирает отчёт-стратегию:

1. **Карта ниши** — границы, подниши, с чего стартовать.
2. **Светофор ниши** — можно ли новичку (доверие + закон РФ: YMYL, 152-ФЗ, реклама).
3. **Проверка выдачи** — пустят ли в топ; кто там сидит, где щели.
4. **Разбор спроса** — язык ниши, кластеры, типы страниц (проверка в Wordstat).
5. **Боли и язык аудитории** — из форумов и отзывов, для заголовков и FAQ.
6. **Деньги-страницы** — где заявки, а где пустой трафик; лиды vs CPA.
7. **Гео и архитектура** — нужны ли города, карта тем, программная сетка.
8. **Стратегия** — контент-план, очередь первых 10–20 страниц, риски, план на 30/90 дней, KPI.

На выходе — файл-стратегия, с которым можно сразу идти строить сайт.

## Установка

Одной строкой (устанавливает в `~/.claude/skills/`):

```bash
curl -fsSL https://raw.githubusercontent.com/vasin-k-i/razvedka-nishi/main/install.sh | bash
```

Или вручную:

```bash
git clone https://github.com/vasin-k-i/razvedka-nishi.git
cd razvedka-nishi && bash install.sh
```

Потом **перезапусти Claude Code**.

## Как пользоваться

В Claude Code напиши `/razvedka-nishi` или просто:

```
Сделай разведку ниши: «натяжные потолки в Казани», зарабатываю на заявках.
```

или дай ссылку на существующий сайт:

```
Прогони разведку ниши для сайта example.ru — оцени сложность входа и что делать.
```

Скилл спросит недостающее (паспорт проекта), проведёт разведку по фазам и сохранит отчёт-стратегию в файл.

**Работает без платных инструментов** — на бесплатном фундаменте (веб-поиск + Wordstat вручную). Если у тебя есть доступ к Wordstat API, Ahrefs, Keys.so — скилл использует и их (глубже), но не требует.

## Что внутри

```
skills/razvedka-nishi/
  SKILL.md              — оркестратор: фазы, инструменты, сборка отчёта
  references/           — глубокая база знаний (подгружается по фазам)
    01-method            — паспорт проекта, 10 правил, цепочка, чек-листы
    02-prompts           — 8 готовых промптов (движок)
    03-serp-competitors  — проверка выдачи, архетипы конкурентов РФ, wedge
    04-demand-wordstat   — семантика, типы частотности, кластеры
    05-audience-language — боли и живой язык (источники РФ)
    06-monetization      — деньги-страницы, лиды vs CPA, маркировка рекламы
    07-ymyl-legal        — YMYL-тест, юр-светофор РФ, страницы доверия
    08-page-types        — гео, карта сущностей, программная сетка, типы страниц
    09-quality-onpage    — он-пейдж/качество: title/desc, canonical, микроразметка, E-E-A-T, off-page, правила НИКОГДА
    10-geo-aeo-tools     — попадание в ответы ИИ (Нейро/AI Overviews) + стек инструментов
    11-report-template   — структура отчёта-стратегии
  assets/report-skeleton — пустой шаблон отчёта
```

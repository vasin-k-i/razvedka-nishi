# Гео и архитектура сайта

Превращает спрос в структуру: карта тем (сущности), типы страниц, программная сетка, решение по гео. Итог — не набор случайных статей, а матрица «шаблон × данные».

## Гео: нужны ли города

1. **Завязана ли ниша на место?** Услуга оказывается физически (ремонт, производство, локальные услуги) → гео важно. Всё онлайн / по всей стране → города не нужны.
2. **Сетка «услуга × город» или одна страница?** Правило: делаем страницу города, **если по нему есть спрос в Wordstat выше разумного порога**; нет спроса — общий раздел. **Не плодить пустые города** (тонкий контент → риск фильтра).
3. **Проверка вживую:** вбей «[услуга] [город]» в Яндексе — есть ли локальная выдача (Яндекс.Карты, Яндекс.Услуги, местные сайты) или топ у федералов. Локальная выдача + слабые местные = шанс.
4. **Старт — 3 города-пилота** (где спрос есть, конкуренция слабее), а не 500 городов сразу.
5. РФ — один язык; разница только по городам/регионам, мультиязычность не нужна.

## Карта тем (сущности) = переменные программной сетки

Раздели тему на:
- **Главные сущности** — ядро (услуги, категории, объекты, направления). Это **переменные** для генерации страниц.
- **Вспомогательные** — поддерживающие темы (гайды, FAQ, глоссарий).
- **Смежные (позже)** — расширение на будущее.

Программная сетка = перемножение осей главных сущностей:
- `услуга × город` (локальные услуги);
- `услуга × материал × город` (производство);
- `направление × категория` (каталоги);
- `товар × характеристика` (товарка);
- `профессия × формат обучения` (образование).

⚠️ Каждая страница сетки должна быть **уникальной по контенту** (локальный/специфический контекст), а не тонким дублем — иначе переспам.

## Типы страниц (шаблоны)

Выбери 3–5 типов на старт под свои кластеры:

| Тип | Под какой спрос | Кластеризация |
|---|---|---|
| Карточка объекта (товар/услуга/город/специалист) | коммерческий, каталожный | Hard |
| Страница услуги | «услуга», «услуга + город» | Hard |
| Сравнение X vs Y | «X или Y», «что лучше» | Hard/Soft |
| Топ / рейтинг-N | «лучшие X», «топ» | Soft |
| Гайд-статья | информационный, «как», «что такое» | Soft |
| FAQ-страница / лендинг | вопросы-возражения | Soft |
| Калькулятор / квиз | «рассчитать», «подобрать» | — |
| Категория / хаб | навигация по кластеру | Hard |

Тип кластеризации (Soft для статей, Hard для коммерции) проставляй по каждому элементу — см. `09-quality-onpage.md`.

## Путь читателя → страницы

- **Разбирается** (инфо) → гайды, FAQ, глоссарий.
- **Сравнивает** → сравнения, рейтинги, топы.
- **Готов** (транзакция) → услуга, карточка, подбор/квиз, лендинг с формой.

Покрыть все три стадии, но деньги — на «сравнивает» и «готов».

## Очередь публикации

Приоритизируй первые 10–20 страниц по формуле: **сначала денежные И низкоконкурентные (wedge)**. Не «все статьи подряд», а самые окупаемые и проходимые в топ первыми. Дальше — расширение сетки и охватный контент.

## Что отдать в отчёт

Решение по гео (нужны города / нет / частично + правило + 3 пилота), карта тем (главные/вспомогательные/смежные), матрица программной сетки (какие оси перемножаем), 3–5 типов страниц на старт с типом кластеризации, и очередь первых 10–20 страниц.

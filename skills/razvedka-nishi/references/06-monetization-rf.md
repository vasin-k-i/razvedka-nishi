# Деньги-страницы и монетизация (РФ)

Отделяет темы, которые дают заявки, от тем, которые дают только трафик. Главная боль новичка: пишет блог, трафик растёт, денег нет — потому что деньги на других страницах.

## Модели заработка (реалистичные для нового сайта РФ)

- **Заявки / лиды** — форма на сайте → заявка уходит тебе / клиенту / партнёру. Подходит для услуг, локального бизнеса, B2B, образования. Метрика — число заявок в неделю.
- **CPA-партнёрка** — переливаешь трафик к партнёру, получаешь за действие. Основные сети РФ: **Admitad, advCake**; тревел — **Travelpayouts**; образование — партнёрки школ (Skillbox и др.). Метрика — клики → действия → выплаты.
- **Реклама** — РСЯ и т.п. Работает только на большом объёме трафика, для нового сайта — не основная модель.
- **Свои услуги/товар** — если у владельца есть что продавать напрямую.

Для новичка реалистичны обычно **две**: заявки/лиды и CPA. Подписки/маркетплейс-модели/консалтинг — редко на старте.

## Где в нише деньги

- **Коммерческие сигналы РФ** (искать в Wordstat, ставить в заголовки денежных страниц): купить, цена, стоимость, заказать, под ключ, срочно, рядом, в [город], отзывы, сравнить, какой выбрать, недорого, на заказ.
- **Ловушки трафика** — темы с большим спросом, но далёкие от денег: «что такое», «своими руками», «бесплатно», развлекательное, справочное. Дают визиты, не дают заявок. На старте — не приоритет (можно позже, для охвата и внутренней перелинковки).
- **Правило:** высокий спрос ≠ деньги. Проверяй отдельно (см. фазу 4 и эту).

## Денежные страницы (делать первыми)

| Тип страницы | Когда | CTA |
|---|---|---|
| Услуга | оказываешь услугу | форма заявки / расчёт стоимости |
| Услуга + город | услуга локальная | форма + локальный контакт |
| Сравнение X vs Y | человек выбирает между вариантами | переход к партнёру / заявка |
| Подбор / квиз | много вариантов, нужен выбор | заявка с результатом квиза |
| Каталог-карточка | товар/объект/специалист | заявка / переход в маркетплейс (CPA) |
| Рейтинг / топ-N | «лучшие X» | CPA-ссылки на участников |
| FAQ-лендинг | закрытие возражений перед покупкой | заявка |

## CPA-нюансы (РФ)

- **Маркировка рекламы обязательна.** Партнёрская ссылка = реклама: нужен `erid`, видимая плашка «Реклама. Рекламодатель [ЮЛ/ИНН]. erid: XXX». Штрафы за отсутствие — серьёзные. Закладывай в шаблон карточки/баннера с самого начала.
- **Ссылки — только `rel="nofollow sponsored"`**, скрытые от индексации (`/go/` роут с 302 + noindex + Disallow), чтобы не передавать вес наружу и не ловить санкции.
- Не полагайся на одну партнёрку — держи резервных партнёров под каждую денежную тему.

## Что отдать в отчёт

Список **денежных кластеров** (с пометкой модели: лид/CPA), для каждого — **тип страницы + CTA**, отдельно — **список тем-ловушек** (не брать на старте), и вывод: какая модель заработка для этой ниши сильнее и почему.

# Проверка выдачи и конкуренты (РФ)

Отвечает на главный вопрос перед стройкой: **пустят ли новый маленький сайт в топ.** Наполовину ручное упражнение.

## Как проверять выдачу

1. Возьми 6–10 главных **денежных** запросов ниши (коммерческих/высокоинтентных, не «что такое X»).
2. Проверь топ-10 по каждому **и в Яндексе, и в Google** — наборы конкурентов часто разные.
3. ⚠️ **Веб-поиск обычно даёт Google-срез.** Реальный Яндекс достаётся хуже. Если есть браузер-инструмент — посмотри Яндекс вживую. Если нет — рассуждай о вероятном Яндексе и **всегда помечай неуверенность**. По опыту, Яндекс к новым доменам ЖЁСТЧЕ: сильнее вес возраста домена, коммерческих факторов (адрес/телефон/отзывы), собственных сервисов (Яндекс.Услуги/Карты/Путешествия/Маркет) и агрегаторов.

## Кто в топе: архетипы конкурентов

Классифицируй доминирующего игрока по каждому запросу:

- **Агрегатор / каталог** — тот же продукт, что каталог-навигатор. Годами копил охват по всей РФ. **Самый жёсткий барьер для сайта-каталога** — в лоб не обойти (вопрос не качества, а возраста домена + охвата + ПФ).
- **Маркетплейс** — Wildberries, Ozon, Авито, Яндекс.Маркет (товарка); Островок, Туту, Level.Travel, Яндекс.Путешествия (travel); Профи.ру, Авито Услуги (услуги). Держат транзакционные запросы структурно (свой инвентарь/бронь) — контент-сайту там нечего ловить.
- **Крупный бренд** — известная компания/вуз/школа с бюджетом и брендовым трафиком.
- **Гос / официальный** — Госуслуги, минведомства, реестры. Держат «официальные» запросы; сами головные коммерческие обычно не забирают, но их цитируют как источник (важно для YMYL-доверия).
- **Медиа / UGC** — vc.ru, dtf.ru, kp.ru, Т-Ж, Mail.ru, Пикабу, Дзен. Ранжируются за счёт авторитета площадки и формата, а не спец-базы. **Уязвимы** к более полезному/актуальному/структурированному контенту.
- **Небольшой сайт / личный блог / нишевый игрок** — если в топе такие, а не гиганты, — **это зелёный сигнал**, туда реально зайти.

## Типовой ландшафт агрегаторов РФ по вертикалям (ориентир, проверять живьём)

- **Образование / курсы / колледжи:** Sravni, postupi.online, vuzopedia, Ucheba.ru, tutortop, edu.sravni; школы-гиганты Skillbox/Нетология/Практикум; кластер институтских ДПО-сайтов.
- **Товары:** Wildberries, Ozon, Яндекс.Маркет, Авито.
- **Услуги (локальные):** Профи.ру, Авито Услуги, Яндекс.Услуги, 2ГИС, Яндекс.Карты.
- **Travel:** Яндекс.Путешествия, Островок, Туту, Level.Travel, Суточно, Tvil, Трипстер, Тонкости туризма; форум Винского.
- **Финансы / подписки / сервисы:** Sravni, Банки.ру, Финуслуги, Т-Банк/РБК-медиа, сам Яндекс.Справка.
- **B2B / производство:** чаще НЕ агрегаторы, а сайты-подрядчики; агрегаторы (Пульс цен, Flagma, Tiu, Всеинструменты) в топе слабее — это шанс.
- **Отзывы/жалобы:** Отзовик, iRecommend, Яндекс.Карты-отзывы, 2ГИС, vc.ru/legal — часто UGC без системного разбора (дыра для экспертного контента).

## Оценка 4 барьеров (светофор)

- 🟢 зелёный — барьер слабый, реально пройти; 🟡 — тяжело, но можно клином; 🔴 — почти непроходимо в лоб.
1. **Доминирование брендов/агрегаторов** — кто в топе денежных запросов.
2. **Доверие / YMYL** — насколько тема требует экспертности/реквизитов (см. `07-ymyl-legal-rf.md`).
3. **Объём контента** — сколько страниц нужно, чтобы конкурировать (глубина ниши).
4. **Ссылки / авторитет** — возраст домена и ссылочный профиль. У нового сайта почти всегда 🔴 — **единственный барьер, который контент сам по себе не решает** (нужен off-page, см. `09-quality-onpage.md`).

## Вердикт

- **go** — топ рыхлый, есть небольшие сайты, барьеры ≤🟡.
- **осторожный go** — смешанно, заходить точечно.
- **поэтапный go** — головы заняты, но есть клин через хвост/подниши/гео. **Самый частый реальный вердикт** для нового сайта в живой нише.
- **no-go** — вся ниша под монополистом (маркетплейс/гос/один непробиваемый агрегатор на всех запросах) → сменить нишу или уйти в узкую поднишу.

## Wedge — точки входа (где снижается сложность)

Не бей в голову — ищи клин:
- **Длинный хвост** — узкие низкочастотные коммерческие запросы, куда гиганты не доходят руками.
- **Гео 2-го эшелона** — города вне Москвы/СПб, где у федералов generic-покрытие.
- **Узкие подниши** — специализация вместо флагманской темы (там меньше конкурентов).
- **Сравнения** — «X vs Y», редакционный жанр, которым каталоги системно не занимаются (у них листинг).
- **Форматы, которых нет у гигантов** — калькулятор, квиз, глубокий разбор, честное сравнение, реальный опыт.
- **Свежесть / first-mover** — новый закон/тренд, который никто ещё не актуализировал.
- **Трение доверия** — контент «как проверить / не обманут ли / на что смотреть в договоре»: низкая конкуренция, укрепляет E-E-A-T.

Для каждого wedge укажи: почему снижает сложность, какой тип страницы нужен, подходит ли новому сайту, горизонт (быстро/средне/долго).

## Что отдать в отчёт

Таблица «запрос → кто в топе (Я/G) → тип победителя → тип страницы → открыт ли для нового сайта», 4 барьера светофором, вердикт, 3–5 wedge с типами страниц. Обязательно строкой: «реальный Яндекс может быть жёстче — по денежным/локальным/брендовым запросам проверить вживую».

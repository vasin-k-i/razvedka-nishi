# Разбор спроса и Wordstat (РФ)

Превращает нишу в карту спроса: реальный язык → кластеры → типы страниц. Ядро семантики, из которого растёт вся сетка.

## Шаг 1. Собери язык ниши (это делает модель)

Люди ищут не «правильными» терминами. Собери 4 слоя формулировок (30–50 стартовых фраз):
- **Официальные термины** — как называется в документах/индустрии.
- **Разговорные синонимы** — как говорят обычные люди («права» vs «водительское удостоверение»).
- **Сокращения и сленг** ниши.
- **Частые опечатки / бытовые искажения**.

Эксперт и новичок ищут разными словами — это буквально разные ключи в Wordstat. Собери оба.

## Шаг 2. Раздели по типам запросов (интент)

- **Информационные:** «что такое», «как», «почему», «своими руками» — трафик, дальше от денег.
- **Выбор/сравнение:** «какой лучше», «X или Y», «рейтинг», «топ», «отзывы» — середина воронки, к деньгам ближе.
- **Коммерческие/транзакционные:** «купить», «цена», «заказать», «стоимость», «под ключ», «услуга» — деньги.
- **Локальные:** «рядом», «в [город]», «недорого [город]» — деньги + гео.
- **Брендовые/навигационные:** «[бренд] отзывы/личный кабинет/вход» — осторожно, часто чужие.

## Шаг 3. Проверь частотности в Wordstat (это делает пользователь или API)

⚠️ **Модель НЕ знает реальных частотностей по РФ — не выдумывай их.** Дай список фраз, пользователь проверяет:
- **Ручной:** wordstat.yandex.ru — вбить фразу, посмотреть частотность и «похожие запросы».
- **Типы частотности (важно, различаются до десятков раз):**
  - широкая `запрос` — все словоформы и словосочетания, включающие слова (сильно завышена);
  - фразовая `"запрос"` — только эта фраза в любых словоформах/порядке;
  - точная `"!запрос"` (или `!слово`) — точная словоформа;
  - для честной оценки денежного спроса опирайся на фразовую/точную, а не на широкую.
- **Регион** обязателен: спрос по РФ ≠ спрос по конкретному городу. Для гео-решения (фаза 7) — сверять по регионам.
- **API / живой Вордстат** (если у пользователя есть) — пакетно снять частотности и кластеризовать; см. `10-geo-aeo-tools.md`.

### Пакетный замер скриптом (если есть ключи)

В скилле лежит `assets/freq.py` — снимает частотности пачкой и сам переключает источники:
глобальный кэш → Yandex Cloud Wordstat → Arsenkin Tools.

```bash
python3 assets/freq.py --in phrases.txt --out freqs.json     # список фраз, по одной в строке
python3 assets/freq.py "купить котёл" "котёл цена"           # быстрая проверка руками
python3 assets/freq.py --stats                                # что уже в кэше и сколько потрачено
```

Ключи (если их нет — скрипт молча ничего не вернёт, работай вручную по шагам выше):
`YANDEX_CLOUD_API_KEY` + `YC_FOLDER_ID` (бесплатно, но **100 запросов в час** на аккаунт),
`ARSENKIN_API_TOKEN` (платно, ~1 юнит ≈ 0,02–0,03 ₽ за фразу, зато берёт пачку за раз).

⚠️ **Две ловушки, из-за которых можно принять решение по мусорным данным:**
- Wordstat на исчерпанной квоте отдаёт пустой ответ, а не ошибку. Наивный код превращает
  это в «частотность 0» = «спроса нет». Скрипт такие фразы просто не возвращает —
  **отсутствие фразы в ответе ≠ отсутствие спроса**, её надо домерить позже.
- Не сверяй свою фразу со строками ответа вручную: API нормализует её по-своему
  (дефис → пробел), и самые частотные темы получают ложный ноль.

## Шаг 4. Сгруппируй в кластеры (6–12 на старте)

- Для **статей** — Soft-кластеризация (широкие смысловые группы; см. `09-quality-onpage.md`). Hard на статьях = каннибализация.
- Для **коммерческих посадочных** — Hard (узко, один интент).
- Каждому кластеру присвой **тип страницы** (статья / карточка / услуга / сравнение / FAQ / категория) и метку **«к деньгам» / «к трафику»**.

## Шаг 5. Учти сезонность и ИИ-поглощение

- **Сезонность:** если ниша сезонная (Wordstat показывает пики по месяцам) — заложить публикацию за 4–8 недель до пика.
- **ИИ съедает клик:** по чисто информационным запросам, где Яндекс.Нейро / AI Overview даёт полный ответ, — занижай прогноз трафика (см. `10-geo-aeo-tools.md`, click-defense). Фокус денег — на транзакционных/локальных, где клик сохраняется.

## Шаг 6. Оцени потенциал ниши (статейная мощь) — обязательно

Для контент-сайта на SEO-машине это критерий не менее важный, чем деньги: машина двигается статейным объёмом, и мало найти денежные страницы — нужно, чтобы было о чём писать месяцами. Оцени 4 вещи:

1. **Инфо-запросы под ЦА.** Для каждого сегмента аудитории (новичок / разбирается / готов; из фаз 1 и 5) выпиши, какие ИНФОРМАЦИОННЫЕ вопросы он задаёт: «как», «что такое», «какой выбрать», «можно ли», «сколько стоит», «почему», «пошагово», «своими руками», «отзывы». Это топливо для статей — именно инфо-спрос под ЦА кормит статейное продвижение (не только «купить»).
2. **Ширина ядра — сколько РАЗНЫХ статейных тем вытянет ниша.** Прикинь порядок величины: десятки / сотни / тысячи тем. Считать по осям: подтемы × сегменты ЦА × форматы (гайд/сравнение/вопрос-ответ/список) × гео (если применимо). Мало тем → конвейеру нечем питаться.
3. **Общий потенциал спроса (в количестве запросов).** Примерный суммарный объём запросов ниши — порядок величины (сотни / тысячи / десятки тысяч показов/мес). ⚠️ **Не выдумывать** — брать из Wordstat по головным фразам кластеров и помечать как оценку. Это потолок трафика.
4. **Запас контента (runway).** Хватит ли тем на выбранный темп: напр. 5 статей/день × 90 дней ≈ 450 тем; 5/день × полгода ≈ 900. Если ниша даёт 40 тем — машина «голодает» через 2 недели.

**Вывод для вердикта:** ниша с лёгким входом, но узким ядром — слабая для контент-SEO (быстро упрётся в потолок тем/трафика). Ниша с широким и растущим инфо-спросом — сильный потенциал, даже если вход небыстрый (есть чем кормить машину и куда расти). Всегда показывай ОБА: сложность входа и статейную мощь, и не подменяй одно другим.

## Что отдать в отчёт

Таблица: **кластер → примеры фраз → тип запроса → частотность (или «проверить в Wordstat») → тип страницы → к деньгам/к трафику**. Плюс: 10 фраз для проверки первыми, пометки по сезонности и по «съедаемым ИИ» кластерам. **И блок «Потенциал ниши»:** инфо-запросы по сегментам ЦА, ширина ядра (порядок числа статейных тем), общий объём спроса (оценка), запас контента на N месяцев — с явным выводом «статейной мощи хватает / впритык / мало».

# Шаблон отчёта: готовая стратегия

Финал разведки — не список наблюдений, а **стратегия, с которой можно идти строить сайт**. Собери отчёт по этой структуре. Каждый раздел — короткий, конкретный, с уровнем уверенности. Не вода: если раздел не превратился в решение/действие — он не готов.

Сохрани в файл `razvedka-<ниша>-<ГГГГ-ММ-ДД>.md`. Пользователю покажи разделы 1 и 13 (executive + действия), остальное — в файле.

---

## Структура отчёта

### 1. Executive verdict (одна страница — самое важное)
- **Вердикт по нише:** go / осторожный go / поэтапный go / no-go — одной фразой + почему.
- **С какой подниши стартовать** и почему именно с неё.
- **Где деньги** (1–2 самых денежных кластера).
- **Главный барьер** и **главная возможность** (wedge).
- **Модель заработка:** лиды / CPA / смешанно.
- **Что делать первым** (1–2 пункта).
- ⚠️ Оговорка про Яндекс, если выдачу смотрели по Google-срезу.

### 2. Оценка ниши (светофор + скоринг)
Таблица барьеров 🟢/🟡/🔴: конкуренция брендов/агрегаторов · доверие/YMYL · объём контента · ссылки/авторитет.
Плюс сводные оценки 1–10 (с обоснованием каждой): привлекательность спроса · близость к деньгам · доступность новичку · сложность входа · итоговая привлекательность с поправкой на риск.

### 3. Карта ниши
Границы (ядро/смежное/не сюда), 3–6 подниш с оценкой (спрос-гипотеза / к деньгам / сложность), выбранная стартовая подниша.

### 4. Семантическое ядро
Таблица кластеров: **кластер → примеры фраз → тип запроса → частотность (или «проверить в Wordstat») → тип страницы → к деньгам/к трафику**. Пометка кластеров, которые «съест ИИ». 10 фраз для проверки первыми.

### 5. Аудитория и язык
2–3 типа читателей, их боли/возражения, живые формулировки (для заголовков), 10 вопросов FAQ, 5 барьеров доверия с решением.

### 6. Модель денег
Денежные кластеры (лид/CPA), для каждого — тип страницы + CTA. Отдельно — темы-ловушки (не брать на старте). Вывод: какая модель сильнее.

### 7. Гео
Нужны ли города (да/нет/частично) + правило «когда делаем страницу города» + 3 города-пилота.

### 8. Архитектура сайта
Карта тем (главные/вспомогательные/смежные сущности), матрица программной сетки (оси), 3–5 типов страниц на старт с типом кластеризации (Soft/Hard).

### 9. Очередь публикации
Первые **10–20 страниц** таблицей: страница/тема → тип страницы → кластер → к деньгам/трафику → приоритет (1/2/3) → почему первой. Сначала денежные + низкоконкурентные.

### 10. Wedge-точки входа
3–5 клиньев: точка входа → почему снижает сложность → тип страницы → горизонт (быстро/средне/долго).

### 11. Риски
- **YMYL / юридические** (светофор из фазы 2, что обязательно учесть, страницы доверия).
- **Конкурентные** (где не пробиться, чего не делать).
- **Правила НИКОГДА** релевантные нише (см. `09-quality-onpage.md`).

### 12. Дорожная карта 30 / 90 дней
- **30 дней:** запустить N денежных + wedge-страниц, поставить формы/аналитику/консоли, страницы доверия.
- **90 дней:** расширить сетку, добить хвост, начать off-page (после 2–3 мес домена), первый рефреш.
- Реалистичные ожидания: молодой домен + ссылочный барьер 🔴 → первые месяцы это долгая игра, деньги с хвоста/wedge, не с голов.

### 13. Что делать на этой неделе
3–5 конкретных действий, которые пользователь может начать сразу. Самое важное — первым.

### 14. KPI
Что мерить: не «топ-10 по ключу», а **заявки/действия в неделю**, трафик по денежным кластерам, позиции по wedge-запросам (для диагностики). Связка «страница → трафик → заявки», а не только позиции.

---

## Требования к отчёту

- Каждый ключевой вывод — с уровнем уверенности (факт / вероятно / гипотеза).
- Ни одной выдуманной цифры: частотности и объёмы — либо из Wordstat/консоли, либо «проверить».
- Всё завязано на действия: из отчёта видно, какие страницы строить и в каком порядке.
- Он-пейдж/качество вплетено (canonical, кластеризация, микроразметка, E-E-A-T, страницы доверия) — стратегия применима сразу, без второго захода.

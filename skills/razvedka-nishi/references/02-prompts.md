# 8 промптов разведки (движок)

Это готовые промпты для каждой фазы. Ты можешь либо выполнять их логику сам (агентно, с проверкой выдачи и поиском), либо отдать пользователю для ручного прогона в отдельном чате. Каждый начинается со вставки паспорта проекта. В каждом зашито «разделяй факт/гипотезу, не выдумывай цифры».

## Промпт 1. Карта ниши
```
Ты — опытный SEO-стратег и аналитик ниш. Помоги разобраться в нише до сборки сайта.
Не длинный отчёт — короткая рабочая карта, по которой можно принять решение.
[ПАСПОРТ ПРОЕКТА]
Сделай:
1. Границы ниши: ядро / смежное / вообще не сюда.
2. 3–6 подниш. Для каждой: что это, много ли спроса (гипотеза), близко ли к деньгам, тяжело ли новичку.
3. Кто клиент: 2–3 типа людей и что каждый ищет.
4. Путь к покупке в 3 стадии: разбирается → сравнивает → готов. Что ищет на каждой.
5. С какой одной подниши стартовать новичку и почему.
Правила: разделяй факты и гипотезы; не выдумывай частотности; широкую нишу сначала разбей на 2–3 куска.
В конце — 5 главных выводов и абзац «с чего начать».
```

## Промпт 2. Светофор ниши: можно ли новичку
```
Ты — SEO-стратег, который бережёт новичка от опасных ниш. Оцени, безопасно ли новичку сюда — доверие и закон (РФ).
[ПАСПОРТ ПРОЕКТА]
Сделай:
1. YMYL-тест (да/нет): тема касается денег? здоровья? безопасности? права? будущего (образование/карьера)?
   Больше «да» — жёстче требования к доверию и экспертности, тяжелее новичку.
2. Светофор рисков (РФ): раздели темы на зелёную (спокойно) / жёлтую (с оговорками+дисклеймер) / красную (не лезть).
   Учитывай: медуслуги/лекарства без лицензии, микрозаймы/крипта/ставки, БАДы без деклараций, юрконсультации
   «от адвоката» без диплома, закон о рекламе, 152-ФЗ (перс. данные из форм).
3. Минимум страниц доверия (о нас, контакты с реквизитами, реальный автор, ссылки на источники, дисклеймер, политика ПДн).
Правила: это не юрконсультация — красная зона → «проверь у юриста». Разделяй факт/предположение.
Вердикт: новичку можно / можно осторожно / лучше другую нишу — и почему.
```

## Промпт 3. Проверка выдачи: пустят ли меня
```
Сначала руками: открой Яндекс И Google, вбей 5–7 главных запросов, выпиши кто в топ-10.
Ты — SEO-аналитик. Оцени шанс нового маленького сайта попасть в топ.
[ПАСПОРТ ПРОЕКТА]
Живая выдача: [запрос — кто в топ-10, по каждому]
Оцени:
1. Кто доминирует: агрегаторы/маркетплейсы / крупные бренды / госсайты / форумы-Дзен / небольшие сайты.
2. Какой тип страницы побеждает (статья/карточка/услуга/сравнение/видео).
3. Есть ли ответ Яндекс.Нейро / AI Overview сверху (тогда клик по общим вопросам уходит ИИ → фокус на транзакции/локалку).
4. Светофор барьеров (🟢/🟡/🔴): конкуренция брендов/агрегаторов; доверие; объём контента; ссылки.
5. Где щели: подниши/города/сравнения/длинный хвост со слабыми сайтами в топе.
Вердикт: go / осторожный go / поэтапный go / no-go + 3–5 точек входа (wedge) + тип страницы под них.
```

## Промпт 4. Разбор спроса (Wordstat)
```
Ты — SEO-семантик. Собери и разложи спрос ниши.
[ПАСПОРТ ПРОЕКТА]
Сделай:
1. Язык ниши: как реально называют тему — официальные термины, разговорные синонимы, сокращения, опечатки. 30–50 фраз.
2. Раздели по типам: что это / как / какой лучше / сравнение / цена-купить-заказать / рядом-в городе.
3. Сгруппируй в 6–12 кластеров, каждому — тип страницы (статья/карточка/услуга/сравнение/FAQ).
4. Отметь коммерческий спрос (к деньгам) vs информационный (к трафику).
Правила: НЕ придумывай частотности — я проверю в wordstat.yandex.ru. Гео = регионы Wordstat. Отделяй факт/гипотезу.
Таблица: кластер → примеры фраз → тип запроса → тип страницы → к деньгам или к трафику. + 10 фраз в Wordstat первыми.
```

## Промпт 5. Боли и язык аудитории
```
Ты — исследователь аудитории. Сначала реально поищи и почитай обсуждения — не выдумывай.
[ПАСПОРТ ПРОЕКТА]
Сделай:
1. 2–3 типа читателей (новичок / разбирается / готов купить): чего боится, что мешает купить.
2. Реальные боли и возражения — конкретные («боюсь что обманут», «непонятно сколько стоит», «а подойдёт ли мне»).
3. Как люди сами формулируют — живым языком (заголовки, H1, FAQ). Источники: подсказки Яндекса/Google, «люди также ищут»,
   отзывы, форумы (Пикабу, Отзовик, iRecommend, Яндекс.Кью, VK, Дзен, YouTube-комменты).
4. Частые вопросы → FAQ.
5. Что вызывает недоверие и как снять на сайте.
Правила: поищи реальные темы, потом пиши; непроверенное помечай как гипотезу.
Таблица: боль → как формулируют словами людей → какая страница закрывает. + 10 вопросов FAQ + 5 барьеров доверия.
```

## Промпт 6. Деньги-страницы
```
Ты — SEO-стратег, который думает про заявки, а не про позиции.
[ПАСПОРТ ПРОЕКТА]
Сделай:
1. Где деньги: темы близко к заявке/покупке vs «ловушки трафика» (визиты есть, заявок нет).
2. Модель заработка: реально ли зарабатывать через заявки/лиды или CPA-партнёрку; что сильнее и почему.
3. Коммерческие сигналы РФ: купить, цена, заказать, стоимость, отзывы, рядом, сравнить, какой выбрать, под ключ, срочно.
4. Денежные страницы первыми: услуга, услуга+город, сравнение, подбор/квиз, каталог-карточка, FAQ-лендинг. Какой CTA.
Правила: не путай высокий спрос с деньгами. Отделяй факт/гипотезу.
Список денежных кластеров + для каждого «страница и CTA» + отдельно список тем-ловушек (не брать на старте).
```

## Промпт 7. Гео: нужны ли города
```
Ты — SEO-стратег по локальному спросу.
[ПАСПОРТ ПРОЕКТА]
Сделай:
1. Завязана ли ниша на гео: услуга на месте (нужны города) или всё онлайн/по стране (не нужны)?
2. Если важно — отдельные страницы по городам (сетка «услуга × город») или одна? Правило: страница города —
   если по нему есть спрос в Wordstat выше порога; нет спроса — общий раздел, без пустых городов.
3. Проверка: вбей «[услуга] [город]» в Яндексе — есть локальная выдача (Карты/Услуги/местные) или топ у федералов?
4. 3 города-пилота (спрос есть, конкуренция слабее).
Правила: РФ — один язык, разница по городам; мультиязычность не нужна. Частотности по городам не выдумывай.
Вердикт: города нужны / не нужны / частично + правило «когда делаем страницу города» + 3 пилота.
```

## Промпт 8. Контент-план и типы страниц
```
Ты — SEO-архитектор. Собери разведку в план сайта.
[ПАСПОРТ ПРОЕКТА]
Выжимка прошлых шагов: [кластеры спроса, боли, денежные темы, решение по гео]
Сделай:
1. Карта тем (сущности): главные / вспомогательные / смежные (позже). Главные = переменные программной сетки
   (услуга × город, направление × категория, товар × характеристика).
2. Типы страниц под кластеры: карточка объекта, сравнение X vs Y, топ/рейтинг-N, гайд-статья, FAQ, калькулятор/квиз,
   категория. Выбери 3–5 на старт.
3. Путь читателя (разбирается → сравнивает → готов) и какие страницы на каждой стадии.
4. Гэпы конкурентов: топ-5 сайтов ниши — чего нет / что слабо / что устарело (это первые темы).
5. Очередь публикации: первые 10–15 страниц (сначала денежные и низкоконкурентные).
Правила: не набор случайных статей, а матрица «шаблон × данные». Отделяй факт/гипотезу.
Типы страниц на старт + карта тем + очередь первых 10–15 страниц с пометкой что первым.
```
